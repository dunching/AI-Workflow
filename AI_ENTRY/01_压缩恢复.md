# 01_压缩恢复

用于同一会话看到自动压缩提示后恢复上下文。

## 使用方式

对 AI 说：

```text
读 压缩恢复文档
```

## 执行规则

不默认全量重读 `Docs/README.md`。除非说明原因，否则不要走完整新会话入口。

先只读确认：

1. `git status --short`
2. `git diff --name-status`
3. 当前 Handoff：`Docs/PROJECT_STATE/01_Handoff.md`
4. 当前 Todo：`Docs/PROJECT_STATE/02_CurrentTodo.md`
5. 当前任务相关事实源、源码或资源文件

## 回复必须区分

- 从压缩摘要/当前上下文继承的内容
- 本轮重新确认的内容
- 不确定或可能丢失的内容

## 安全边界

- 不凭压缩摘要直接修改文件。
- 沿用已有明确授权；不凭压缩摘要扩大范围，也不为同一已授权工作重复确认。
- 不取消源码确认。
- 状态不确定、任务高风险、规则可能变化或用户要求完整入口时，升级到 `Docs/AI-Workflow/AI_ENTRY/00_新会话.md`。
