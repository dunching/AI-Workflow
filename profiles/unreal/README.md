# Unreal Engine 规则路由

本目录是插件随包的 UE 默认规则，不是项目政策或状态副本。仅确认当前项目或当前工作范围属于 Unreal Engine 时读取本路由；非 UE 项目不加载本目录规范与配置，也不遍历全部 profiles。

## 确认与加载

- 从项目根 AGENTS.md、项目政策、实际 `.uproject` / `.uplugin` 描述及相关源码确认 UE 身份与引擎版本。混合仓库按本次工作的 UE 范围应用，不因一个孤立文件名将规则施加到整个仓库；信息不足时先核对，不猜测。
- 新会话确认 UE 后，读取[UE 编码规范](UE编码规范.md)及项目明确指定的覆盖政策，并读取本次实际生效的格式化配置；默认配置为本目录的 [.clang-format](.clang-format)。无需等待开始改 C++ 才建立规则基线。
- 在上位指令允许范围内，用户明确指令、项目 AGENTS.md 和项目明确指定的编码政策/格式化配置优先于插件默认；项目未覆盖的部分仍使用插件规范。不得因默认配置可用而绕过项目指定项；冲突、路径缺失或指定不清时明确报告并澄清，不静默回退。

## 实际路径与工具

- 插件资源从当前已加载技能及本文件的相对链接解析；项目覆盖路径从项目实际入口解析。记录规范来源、覆盖项、实际配置的绝对路径，以及工程指定 clang-format 的路径和实际版本，不硬编码插件缓存、盘符或某个项目的 Docs 路径。
- 插件安装不会自动把配置复制到项目根，也不会让编辑器自动发现它。执行格式化和 `--dry-run --Werror` 检查时，均显式指定同一份已确认配置，例如使用工程工具支持的 `--style=file:<实际配置绝对路径>`，并正确引用含空格路径；不依赖当前目录向上搜索。
- 工具缺失、指定配置不可读、配置不被实际工具版本支持，或头文件顺序被破坏时，报告阻断；不得擅自安装、更换工具、修改配置或静默采用默认风格。YAML 可解析不代表 clang-format 接受该配置，只有实际执行后才能报告格式检查通过。
- 只格式化本任务修改的项目自有 C++ 文件；完整格式化、验证与人工复核要求以规范正文为准。本路由不授权复制配置、批量重排、安装工具或扩大任务范围。

## 压缩恢复与变化

压缩恢复继承可靠且未变化的 UE 身份、规范来源、项目覆盖、实际配置路径及工具路径/版本，明确标为继承，不假称重新读取或执行。按当前项目、引擎、插件版本、政策、配置或工具的相关变化定向补读；来源缺失、不确定或冲突时重新确认。普通恢复不重读全部 profiles，也不重复新会话全套流程。
