# 收敛清理与整理重构

读取并执行[收敛清理与整理重构流程](../../AI_WORKFLOW/13_收敛清理与整理重构.md)，按[工作流入口](../../AI_WORKFLOW/00_工作流入口.md)保留项目约束和持续回复格式。

按用户指定的模块、目录或当前任务收口。只要求审查或方案时输出候选与证据；要求实施且范围可确定时，连续完成整理、受影响调用方迁移和集中验证。
