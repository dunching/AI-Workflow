# 提交推送

读取并执行[提交推送流程](../../AI_WORKFLOW/12_提交推送.md)，按[工作流入口](../../AI_WORKFLOW/00_工作流入口.md)保留项目约束和持续回复格式。

显式调用且未指定阶段时，执行当前任务的提交后推送。自然语言按实际请求选择阶段。引用、说明、编写流程或只要求拟提交消息时，提供相应材料；提交与推送按实际执行意图授权。
